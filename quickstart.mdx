MCGalaxy runs on Windows, macOS, and Linux. This guide walks you from a fresh download to a running server where you can connect and play. The whole process takes under five minutes.

## System requirements

<Tabs>
  <Tab title="Windows">
    Windows 8, 10, or 11 already include .NET Framework 4.0. No extra install needed.

    For .NET 6/7/8 builds, install the [.NET runtime](https://dotnet.microsoft.com/download) for your target version.
  </Tab>
  <Tab title="macOS">
    Install the [Mono framework](https://www.mono-project.com) to run the prebuilt release.

    Alternatively, install the .NET SDK to compile and run a .NET 6/7/8 build.
  </Tab>
  <Tab title="Linux">
    Install Mono:

    ```bash
    # Ubuntu/Debian
    sudo apt install mono-complete

    # Or install the .NET runtime for .NET 6/7/8 builds
    ```
  </Tab>
</Tabs>

## Download

Download the latest MCGalaxy release from [classicube.net/mcg/download](https://www.classicube.net/mcg/download/). Extract the zip to a folder of your choice.

## Start the server

<Steps>
  <Step title="Launch MCGalaxy">
    <Tabs>
      <Tab title="Windows (GUI)">
        Double-click **MCGalaxy.exe** to open the graphical interface. The console log window appears and the server starts on port `25565`.
      </Tab>
      <Tab title="Windows (CLI)">
        Run **MCGalaxyCLI.exe** from a Command Prompt for headless operation:

        ```bash
        MCGalaxyCLI.exe
        ```
      </Tab>
      <Tab title="macOS / Linux">
        Run via Mono:

        ```bash
        mono MCGalaxyCLI.exe
        ```

        Or use the included helper script:

        ```bash
        chmod +x mcf.sh
        ./mcf.sh
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step title="Connect to your server">
    Open the ClassiCube client, click **Direct connect**, enter:

    - **Username**: your ClassiCube account name
    - **IP:Port**: `127.0.0.1:25565`
    - **Mppass**: leave blank

    Then click **Connect**.
  </Step>
  <Step title="Give yourself owner rank">
    In the MCGalaxy console window (or the bottom input of the GUI), type:

    ```
    rank [yourusername] owner
    ```

    You now have full access to all commands.

    <Warning>
      Type the command directly in the server console — do NOT use `/rank` with the slash prefix in the console.
    </Warning>
  </Step>
</Steps>
