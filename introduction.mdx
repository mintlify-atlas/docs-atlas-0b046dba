MCGalaxy is an open-source ClassiCube/Minecraft Classic server software built on the foundation of MCForge and MCLawl. It gives you everything you need to run a feature-rich ClassiCube server — from player ranks and moderation tools to world building, mini-games, and an extensible plugin system for writing your own custom functionality in C#.

## Get started

<Steps>
  <Step title="Download MCGalaxy">
    Download the latest release from [classicube.net/mcg/download](https://www.classicube.net/mcg/download/) for your platform.
  </Step>
  <Step title="Launch the server">
    Run `MCGalaxy.exe` for the graphical interface, or `MCGalaxyCLI.exe` for command-line only operation.
  </Step>
  <Step title="Join and rank yourself">
    Connect via the ClassiCube client or web browser, then run `/rank [yourname] owner` in the server console to grant yourself full access.
  </Step>
  <Step title="Invite others">
    Port forward port `25565` and share your server URL or IP address with players, or make it public on the ClassiCube server list.
  </Step>
</Steps>
