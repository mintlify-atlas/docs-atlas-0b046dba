MCGalaxy ships with a large set of built-in commands covering everything from block drawing tools to economy transactions. In-game, commands are entered with a `/` prefix (e.g. `/help`). From the server console or IRC, omit the `/` prefix and type the command name directly (e.g. `help`). Most commands have shortcuts — single letters or short strings that trigger the full command.

To get detailed help on any command, use:

```
/help [command]
```

To list all commands available to your rank:

```
/commands
```

## Building commands

Building commands let players draw and modify blocks in the world. Most require the player to mark positions by placing or breaking blocks.

| Command | Shortcut | Description |
|---------|----------|-------------|
| `/Copy` | | Copies a selected region to the clipboard. |
| `/Paste` | | Pastes the clipboard contents at the current position. |
| `/Cuboid` | `z` | Fills a rectangular region with a block. |
| `/Sphere` | | Draws a filled sphere. |
| `/Spheroid` | | Draws a filled spheroid (ellipsoid). |
| `/Replace` | `r` | Replaces all instances of one block with another in a region. |
| `/ReplaceNot` | `rn` | Replaces everything except a specified block in a region. |
| `/Undo` | `u` | Undoes your own recent block changes. |
| `/Redo` | | Re-applies changes that were undone. |
| `/Draw` | `d` | Draws lines, curves, and other geometric shapes. |
| `/Fill` | | Flood-fills an enclosed area. |
| `/Hollow` | | Makes the interior of a solid shape empty. |
| `/Outline` | | Draws the outer shell of a region with a different block. |
| `/Line` | | Draws a line between two points. |
| `/Torus` | | Draws a torus (donut shape). |
| `/Pyramid` | | Draws a pyramid. |
| `/Tree` | | Generates a tree structure. |
| `/Maze` | | Generates a random maze. |
| `/Mirror` | | Mirrors a selected region. |
| `/Spin` | | Rotates a copied region. |
| `/Transform` | | Applies matrix transformations to a region. |
| `/Brush` | `b` | Sets the brush used by drawing commands. |
| `/Mark` | `m` | Marks a position as a selection point. |
| `/Abort` | `a` | Cancels the current drawing operation. |
| `/Undo` | `u` | Reverts your recent block placements. |
| `/WriteText` | | Writes text using blocks. |
| `/ImagePrint` | | Renders an image as blocks. |
| `/MessageBlock` | `mb` | Places a block that sends a message when activated. |
| `/Portal` | | Creates a portal block that teleports players. |
| `/Measure` | | Reports the dimensions of a selected region. |
| `/Mode` | | Toggles a block placement mode (e.g. paint mode). |
| `/Paint` | | Enables paint mode (replace instead of place). |

<Tip>
Most building commands require you to select a region by placing or breaking two blocks. Use `/Mark` to mark a position without placing a block, and `/Abort` to cancel any active operation.
</Tip>

## Command shortcuts

Many commands have one or more shortcut aliases. For example, `/Kick` has shortcut `k`, so `/k PlayerName` works identically to `/Kick PlayerName`. Aliases can also pass preset arguments — for example, `/Promote` is an alias for `/SetRank +up`.

Use `/Help [command]` to see both the full syntax and any defined aliases for a given command.
